## Projects

- **[dropzone](https://github.com/nickyjacobs/dropzone): Per-Box Shell Tooling for Kali**  
  Zsh plugin that sets up a work folder, Obsidian note, target variables and hosts entry for a box in one command. The note template is built around methodology checklists that grow after every box. Handles admin only, no scans or exploits, so it is allowed during the OSCP exam.

- **[CYRIX MK-III](https://github.com/nickyjacobs/CYRIX-MK-III): Personal AI Assistant on Claude Code**  
  Self-built assistant system with its own skills, agents and memory. The knowledge base follows Andrej Karpathy's LLM wiki pattern in Obsidian: the model builds and maintains its own markdown wiki and reads only the pages it needs.

- **[JacOps Homelab](https://github.com/nickyjacobs/JacOps-Homelab): Security-First Proxmox Environment**  
  Two-node Proxmox cluster behind a UniFi gateway with VLAN segmentation, zone-based firewalling, WireGuard and an isolated offensive zone. Internal TLS through Traefik and an in-house PKI (step-ca), monitoring and backups included. Documented as portfolio and runbook.

- **[DutchQuill AI](https://github.com/nickyjacobs/DutchQuill-AI): Dutch Academic Writing Assistant**  
  Claude Code assistant that rewrites Dutch texts to APA 7, detects and removes AI patterns across twenty categories, analyses readability and exports to .docx.

- **Systems Security capstone: Roots of the Roundtable** (NOVI, 2026)  
  Designed and built an original HackTheBox-style vulnerable VM with a known CVE, pivoting and privilege escalation. Pentested two fellow students' environments following PTES, with findings classified using CWE and OWASP Top 10 and scored with CVSS v3.1.
